# prompt-test

유명한/눈에 띄는 프롬프트를 그대로 실행해서 결과물을 확인해보는 실험 폴더. 여기 들어가는 프로젝트는 정식 포트폴리오가 아니라 "이 프롬프트를 넣으면 뭐가 나오는지" 테스트한 결과물이다. 각 하위 폴더에 원본 프롬프트를 담은 `PROMPT.md`를 둔다.
